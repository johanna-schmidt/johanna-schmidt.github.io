# johanna-schmidt.github.io

Personal website and online projects of Johanna Schmidt, Postdoctoral Researcher at the Institute of Visual Computing, TU Graz.

Live at **https://johanna-schmidt.github.io/**

## Contents

| Path | What it is |
|------|------------|
| `index.html`, `css/`, `js/`, `data/`, `img/` | Personal website: profile, publications, press & media, projects |
| [`selective-angular-brushing/`](https://johanna-schmidt.github.io/selective-angular-brushing/) | Interactive demo of selecting lines in parallel coordinate plots by their angle (EuroVis 2021) |
| [`histogram-uncertainty/`](https://johanna-schmidt.github.io/histogram-uncertainty/) | Explore how uncertain different histogram binnings are for a data distribution |
| [`motorbikes/`](https://johanna-schmidt.github.io/motorbikes/) | Visualization of seat heights and engine sizes of motorbikes |

## Updating the website

Content lives in `data/`:

- `publications.js` – publication list
- `press.js` – press and media coverage
- `projects.js` – projects shown in the Projects tab

Open `index.html` in a browser to preview. Pushing to `main` publishes the changes via GitHub Pages.
